Principales Métodos HTTP

  • GET: Se utiliza para solicitar o leer datos de un servidor. No modifica la información.
    Ejemplo: Obtener la lista de productos de una tienda.
  • POST: Se utiliza para enviar datos al servidor para crear un nuevo recurso.
    Ejemplo: Registrar un nuevo cliente en la base de datos.
  • PUT: Se utiliza para actualizar por completo un recurso existente o crearlo si no existe.
    Ejemplo: Actualizar todos los datos del perfil de un usuario.
  • PATCH: Se utiliza para aplicar modificaciones parciales a un recurso.
    Ejemplo: Cambiar únicamente la contraseña de un usuario, sin afectar el resto de sus datos.
  • DELETE: Se utiliza para eliminar un recurso específico del servidor.
    Ejemplo: Borrar un producto que ya no se venderá en la tienda.
